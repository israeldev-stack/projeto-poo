DESCRIÇÃO DETALHADA DE TODO O PROJETO A soma total de todas as avaliações para este projeto resulta em 4,0 (40% da nota da G2)

O Projeto final desta disciplina consiste em escrever um sistema completo para resolver algum problema. O grupo escolhe qual problema irá implementar.

A implementação deve ser feita 100% em python orientado à objetos e deverá ter, necessariamente, os seguintes requisitos:

Pelo menos 5 classes Pelo menos 1 caso de: herança polimorfismo associação método privado atributo privado Programa principal deve criar pelo menos dois objetos Tudo no sistema deve ser implementado. O grupo pode usar bibliotecas gráficas para melhorar o visual.

O trabalho terá várias etapas, avaliada interindividualmente pelo professor e com orientações de melhorias em cada uma:

15/10 - Definição dos grupos (até 4 integrantes). Configuração no Lex. Pesquisa por uma implementação.

22/10 - Etapa 1. Entrega da proposta.

29/10 - Etapa 2. Entrega de parte da documentação. Diagrama de classes, exemplo de telas e forma de interação com o usuário.

05/11 - Etapa 3. Entrega final de toda a documentação. Demonstração, em aula, para o professor, do estado atual do projeto.

19/11 - Final. Entrega final do projeto. Apresentação, em aula, com demonstração. Preparação de slides de apresentação.
